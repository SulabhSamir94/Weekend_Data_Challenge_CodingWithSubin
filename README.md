# 🚀 Weekend Colab Lab

Welcome to my personal code repository! Every weekend, I dive into Python, explore algorithms, and test out ideas using Google Colab. This repository serves as a centralized log of my weekly practice, experiments, and mini-projects.

## 📂 Structure

The notebooks are organized by themes or weekly sprints:
* **`algorithms-and-datastructures/`** — Implementations of core data structures, sorting algorithms, and problem-solving practice.
* **`python-experiments/`** — Exploring Python features, libraries, and scripting snippets.
* **`mini-projects/`** — Small standalone projects built in a single weekend.

## 🛠️ How to Run

You can view these files directly on GitHub, or click the badge at the top of any notebook to open and run it instantly in your browser via Google Colab.
